# Picture's Up — by Cinevision

Script breakdown, stripboard scheduling, call sheets, sides, budgets and Final Draft–style revisions in one desktop app that works offline.

**Get the free beta:** [canyonprince.com/picturesup](https://canyonprince.com/picturesup)

This repository only hosts the installers. Download the newest one from [Releases](https://github.com/notaking2024/picturesup-releases/releases/latest).

## Install (Windows 10 or 11, 64-bit)

1. Download `PicturesUp-Setup-Windows.exe` from the [latest release](https://github.com/notaking2024/picturesup-releases/releases/latest).
2. Open it. It installs and opens Picture's Up. There's nothing else to set up.
3. Beta builds aren't code-signed yet. If Windows shows "Windows protected your PC", click **More info → Run anyway**.

The Mac version is coming soon. Installed copies tell you when a new version is available.
